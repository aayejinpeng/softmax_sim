## Case Notes

- `softmax_fma_exp_approx`
  - description: Softmax using a six-FMA polynomial approximation for exp2 when no dedicated EXP2 unit is available.
  - parameters:
    - num_heads: number of independent attention heads to simulate.
    - seq_chunk_bits: input size per head; larger values increase the number of vector-sized chunks per head.
    - exp2_unit: false selects the FMA polynomial path. These six FMA instructions are an implementation alternative to the single EXP2 instruction in softmax_exp2_unit.
    - fma_exp_dependencies: I03 depends on I02; I04 depends on I03; I05 depends on I04; I06 depends on I05; I07 depends on I06; I08 depends on I07.
    - exp_result_fanout: I08 is the exp result. I09 STORE(exp scratch) and I10 REDUCE(sum exp) both depend on I08.
    - final_div_dependencies: I11 LOAD(exp scratch) depends on I09. I12 FMA(div by sum) depends on I11 and on every I10 sum-reduction chunk. I13 STORE(output) depends on I12.
    - lanes: number of independent contexts that can issue in parallel.
    - issue_width: maximum uops issued per cycle across all lanes.
    - lane_stride_0: per-lane input stride for vlane0 loads.
    - lane_stride_1: per-lane output stride for vlane1 stores.
    - lane_stride_3: scratch stride for the exp-reload path used in this softmax model.
  - dependency chain: LOAD(input) -> REDUCE(max) -> LOAD(subtract) -> FMA(poly1) -> FMA(poly2) -> FMA(poly3) -> FMA(poly4) -> FMA(poly5) -> FMA(poly6) -> REDUCE(sum) + STORE(exp scratch) -> LOAD(exp scratch) -> FMA(div) -> STORE(output)
  - single-chain latency diagram:
    ```text

    cycle 000-010  I00 LOAD(input)              latency 10
    cycle 010-024  I01 REDUCE(max)              latency 14
    cycle 024-034  I02 LOAD(input/sub source)   latency 10
    cycle 034-038  I03 FMA(exp poly 1)          latency 4
    cycle 038-042  I04 FMA(exp poly 2)          latency 4
    cycle 042-046  I05 FMA(exp poly 3)          latency 4
    cycle 046-050  I06 FMA(exp poly 4)          latency 4
    cycle 050-054  I07 FMA(exp poly 5)          latency 4
    cycle 054-058  I08 FMA(exp poly 6)          latency 4
    cycle 058-072  I10 REDUCE(sum exp)          latency 14
    cycle 058-068  I09 STORE(exp scratch)       latency 10
    cycle 068-078  I11 LOAD(exp scratch)        latency 10
    cycle 078-082  I12 FMA(div by sum)          latency 4, waits for I10 and I11
    cycle 082-092  I13 STORE(output)            latency 10
    ```
- `softmax_exp2_unit`
  - description: Softmax using a dedicated EXP2 unit; EXP2 replaces the six dependent FMA polynomial stages.
  - parameters:
    - num_heads: number of independent attention heads to simulate.
    - seq_chunk_bits: input size per head; larger values increase the number of vector-sized chunks per head.
    - exp2_unit: true selects the dedicated EXP2 path. I08 EXP2 replaces I03-I08 from softmax_fma_exp_approx and produces the same logical exp result for downstream users.
    - exp2_dependency: I08 EXP2 depends on I02 LOAD(input/sub source), which already waits for all max reductions for this head.
    - exp_result_fanout: I09 STORE(exp scratch) and I10 REDUCE(sum exp) both depend on I08.
    - final_div_dependencies: I11 LOAD(exp scratch) depends on I09. I12 FMA(div by sum) depends on I11 and on every I10 sum-reduction chunk. I13 STORE(output) depends on I12.
    - lanes: number of independent contexts that can issue in parallel.
    - issue_width: maximum uops issued per cycle across all lanes.
    - lane_stride_0: per-lane input stride for vlane0 loads.
    - lane_stride_1: per-lane output stride for vlane1 stores.
    - lane_stride_3: scratch stride for the exp-reload path used in this softmax model.
  - dependency chain: LOAD(input) -> REDUCE(max) -> LOAD(subtract) -> EXP2 -> REDUCE(sum) + STORE(exp scratch) -> LOAD(exp scratch) -> FMA(div) -> STORE(output)
